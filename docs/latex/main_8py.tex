\doxysubsection{Detailed Description}
Library for fundamental data structures (General Tree, BST) and 2D geometric shapes. 

This module provides basic implementations for tree nodes (general N-\/ary and binary search tree) and common geometric primitives (Point, Line\+Segment, Circle, Polygon) with transformation methods.
